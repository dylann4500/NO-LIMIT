# Build-hour tests of the first prompt (2026-11-12)

Two agents each played our coding agent on an unfamiliar mock variant (a turn draw; a flop card pass),
with prompt pack Part 1, the mock kit and a 60-minute box, clean-room. The reports are here; the bots
they built stay in the scratch folder (they are not for Sunday: no code may be brought). Both reached a
legal bot in under 2 minutes and three styles in under 20, faster than a team steering by hand will.
Their findings were folded into Part 1 the same day: test harness by minute 15, the current hand rebuilt
from history, the ICM call/fold wrapper tests, interleaved scoring of twist options, styles defined on
today's simulated ranking, hour-one scope, subagents wrap rather than copy shared code.
